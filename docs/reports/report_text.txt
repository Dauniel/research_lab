​Automated Python-Based Image Analysis Pipeline for​
​Segmentation and Quantification of Biomolecular Condensates​
​in Fluorescence Microscopy Z-Stacks​
​1. Abstract​
​This project aims to develop a fully automated, reproducible Python-based image analysis​
​pipeline for fluorescence microscopy data to study biomolecular condensates in nuclear and​
​cytoplasmic compartments. Using multi-channel Z-stack images from the JABr dataset, nuclei​
​and condensates are segmented using pretrained Cellpose models implemented directly in​
​Python. A preliminary comparison with a Python-native segmentation led to the selection of​
​Cellpose for accurate and consistent object detection. Segmented masks are used to classify​
​condensates as nuclear or cytoplasmic based on spatial overlap with nuclei. Quantitative​
​object-level features are extracted across Z-slices, and the pipeline generates reproducible​
​outputs including segmentation masks and structured summary tables. This framework enables​
​scalable analysis of condensate behavior and supports future extensions such as time-lapse​
​tracking.​
​2. Introduction​
​Biomolecular condensates are membrane-less cellular compartments that play important roles in​
​processes such as gene expression and RNA regulation. Recent work from the Franco lab has​
​shown that artificial RNA condensates can be engineered in living cells using programmable​
​RNA nanostar motifs, which form distinct compartments in both the nucleus and cytoplasm​
​through sequence-specific interactions [1].​
​Fluorescence microscopy enables visualization of these condensates; however, extracting​
​quantitative and reproducible measurements from multi-channel Z-stack imaging data remains​
​challenging. Manual and GUI-based approaches are difficult to scale and lack reproducibility,​
​particularly when analyzing large datasets or comparing results across experimental conditions.​
​To address these limitations, this project develops an automated Python-based pipeline for​
​condensate segmentation and quantification. The pipeline uses Cellpose models for nuclei and​
​condensate segmentation, followed by compartment classification based on spatial overlap and​

​3. Data Description​
​3.1 Biological Context and Dataset​
​The data used in this project originates from experiments involving engineered RNA nanostar​
​constructs designed to form synthetic biomolecular condensates in living cells. RNA nanostars​
​are programmable RNA structures composed of multiple stem-loop arms connected by flexible​
​spacers, enabling interactions that drive phase separation. These condensates serve as a model​
​system for studying RNA-driven phase separation [1,2].​
​The naming convention for the RNA nanostar constructs reflects their structural design. In this​
​dataset, JABr denotes a construct containing a 15-nt stem, a kissing-loop sequence (A), and the​
​Broccoli fluorescent aptamer. These features influence interaction strength, condensate​
​formation, and subcellular localization.​
​3.2 Dataset Organization and Baseline Reference​
​The dataset used in this project is part of a larger collection of fluorescence microscopy images​
​and associated analysis outputs. It was previously analyzed using Cellpose-based segmentation​
​and manual annotation, providing a reference baseline for validating the automated pipeline.​
​Relevant components include:​
​●​ ​Source Data: raw microscopy images​
​●​ ​Cut ROI: cropped regions of interest​
​●​ ​Masks: segmentation masks for nuclei and condensates​
​●​ ​Statistics / Partition Coefficient: processed quantitative outputs​
​These outputs serve as a reference for comparison with results generated by the pipeline.​

​4. Pipeline Overview​
​The image analysis pipeline follows a structured workflow to ensure reproducibility and​
​scalability.​
​Raw Data → Channel Separation → Nuclei Segmentation →​
​Condensate Segmentation → Compartment Classification → Feature​
​Extraction → Outputs (Masks, Graphs, and CSV Tables)​
​This workflow integrates segmentation with downstream quantitative analysis in a reproducible​
​framework.​
​5. Methods​
​5.1 Channel Interpretation​
​The analysis was performed on the sample​
​20240516_JABr_40uMDFHBI_20-40_Sample2_5_MMStack_Pos0.ome.tif. The two channels​
​were separated prior to analysis, with channel 1 used for nuclei segmentation and channel 2 used​
​for condensate segmentation. The separated files were stored as C1-raw_stack_sample2_5.tif for​
​nuclei and C2-raw_stack_sample2_5.tif for condensates.​
​5.2 Cellpose-Based Segmentation in Python​
​Segmentation was implemented directly in Python using Cellpose. Separate model instances​
​were initialized for nuclei and condensate channels with GPU acceleration enabled. Each Z-slice​
​was processed independently using model.eval() to generate instance segmentation masks. Both​
​full-image and ROI-based analyses were performed to enable comparison with reference outputs.​
​5.3 Quantitative Feature Extraction​
​For each segmented object, quantitative measurements were extracted using regionprops_table​
​from the scikit-image library. The extracted features included object label, area, centroid​
​coordinates, and mean fluorescence intensity.​

--- PAGE 6 ---
​Chang​​6​
​●​ ​Object label: unique identifier assigned to each segmented object within a Z-slice​
​●​ ​Area: number of pixels belonging to the object​
​●​ ​Centroid coordinates: spatial location of the object center, given as (centroid-0,​
​centroid-1) corresponding to row (y) and column (x) positions​
​●​ ​Mean fluorescence intensity: average pixel intensity within the segmented object,​
​computed from the raw fluorescence image​
​The measurements were computed independently for each Z-slice and aggregated into​
​structured CSV tables for downstream analysis. These datasets were then used to generate​
​summary graphs, including distributions of object area and mean fluorescence intensity, as​
​well as object counts across Z-slices. Together, these outputs allow quantitative​
​characterization of both nuclei and condensates, including size distributions, spatial​
​localization, and intensity-based properties.​
​The pipeline also computes the nuclear partition coefficient, a summary measure of condensate​
​enrichment. It is defined as the ratio of mean condensate intensity within nuclei to the mean​
​dilute-phase intensity in the surrounding nuclear region outside condensates, using nuclei and​
​condensate masks applied to the raw fluorescence images.​
​●​ ​Condensate intensity: pixels within nuclei ∩ condensates​
​●​ ​Dilute phase: pixels within nuclei but outside condensates​
​●​ ​Partition coefficient = condensate intensity / dilute-phase intensity​
​5.4 ROI-Based Analysis and Validation​
​The pipeline was applied to a cropped ROI for direct comparison with reference masks and​
​dataset-derived statistics. This enabled both qualitative validation of segmentation accuracy and​
​quantitative comparison using the partition coefficient.​

​6.4 Partition Coefficient Analysis​
​The nuclear partition coefficient was computed to quantify condensate enrichment within nuclear​
​regions. For the full image stack, the pipeline produced a condensate density of 249.17 and a​
​dilute-phase density of 146.05, resulting in a partition coefficient of 1.71.​
​For the ROI, the pipeline produced a condensate density of 337.87 and a dilute-phase density of​
​165.31, resulting in a partition coefficient of 2.04. The ROI-based value is higher than the​
​full-image result, consistent with reduced background influence within the cropped region.​
​However, both values remain lower than the reference partition coefficient of 6.32.​
​7. Discussion​
​This project developed an automated Python-based pipeline for segmentation and quantitative​
​analysis of biomolecular condensates from fluorescence microscopy Z-stacks. Overall, the​
​results show that the pipeline can generate reproducible masks, extract object-level​
​measurements, and compute a biologically meaningful summary metric through the nuclear​
​partition coefficient.​
​Segmentation performance was stronger for nuclei than for condensates. Nuclei were detected​
​consistently across the Z-stack and produced well-defined regions for downstream analysis. In​
​contrast, condensates were more difficult to segment because they are smaller, more​
​heterogeneous in intensity, and more sensitive to background signals. Although the pipeline​
​captured the major punctate condensate structures, some low-intensity regions and possible​
​artifacts were also included.​
​The quantitative results reflect these differences. Nuclei showed relatively stable object counts​
​and more uniform size distributions, while condensates showed greater variation in count, area,​
​and intensity across slices. This suggests that the pipeline is able to distinguish meaningful​
​differences between the two object classes, while also showing that condensate measurements​
​are more sensitive to segmentation quality.​
​The partition coefficient analysis further highlights both the usefulness and the limitations of the​
​workflow. The ROI-based value (2.04) was higher than the full-image value (1.71), indicating​
​improved local signal contrast when background is reduced. However, both values were lower​
​than the reference value of 6.32. This suggests that small differences in condensate boundary​
​detection can substantially affect downstream intensity-based measurements.​
​Overall, the pipeline provides a reproducible and scalable framework for condensate analysis,​
​but the results also show that accurate quantitative interpretation depends heavily on​
​segmentation quality. Future improvements could include additional parameter tuning,​

​8. Reproducibility​
​The analysis pipeline was implemented entirely in Python using open-source libraries, including​
​Cellpose for segmentation, NumPy and pandas for data processing, and scikit-image for feature​
​extraction. All steps, including image loading, segmentation, quantitative feature extraction, and​
​visualization, were executed through a single, reproducible workflow.​
​The pipeline operates on standardized input files, including multi-channel Z-stack TIFF images,​
​and produces consistent outputs in the form of segmentation mask stacks (TIF) and quantitative​
​measurement tables (CSV). File organization and naming conventions were structured to ensure​
​clarity and ease of reuse.​
​GPU acceleration was used to improve computational efficiency during segmentation, enabling​
​scalable analysis of large image stacks. The modular design of the pipeline allows it to be applied​
​to additional datasets or extended with minimal modification.​
​A limitation of the pipeline is its dependence on available computational resources. While GPU​
​acceleration substantially reduces runtime, execution on systems without a GPU (e.g., standard​
​laptops) may be significantly slower, particularly for large Z-stack datasets. This may impact​
​scalability and processing time in resource-constrained environments.​
