Batch Validation: 30 JABr Cells (Central Nucleus + Top-75% Trimming)

After optimizing nucleus selection heuristic and condensate density trimming,
we validated across all 30 JABr cells with manual reference PCs:

Batch Performance (n=29 after NaN removal):
  • Pearson r        : 0.735
  • RMSE             : 2.815
  • Mean Error       : +2.8%
  • Within 20% error : 21/29 cells (72%)

  Sample3_3_3   ref=8.82   pipeline=8.74    error=−1.0%

  Sample3_3_1   ref=8.18   pipeline=8.31    error=+1.5%
  Sample1_4_1   ref=6.13   pipeline=6.20    error=+1.1%

Segmentation Quality Advantage:
  → Cellpose 3D mode maintains boundary consistency across Z-slices
  → No slice-stitching artifacts (2D mode splits each nucleus ~3 times)
  → Connected-component cleanup removes false fragments
  → Dilute-phase sampling now deterministic and representative

Known Outliers (Segmentation Failures, Not Calibration):
  Sample3_3_15 (NaN)        → central nucleus too small, zero condensate overlap
  Sample1_1_1 (error +146%) → mask inflated, nucleus selection correct
  Sample3_3_2 (error −51%)  → condensates underestimated in detection
  Sample3_3_11 (error −38%) → bright core undersampled
  Sample2_5_5 (error −38%)  → wide FOV, nucleus not detected

Conclusion: Pipeline is well-calibrated on typical single-nucleus FOVs.
Remaining errors stem from segmentation model limitations (Cellpose cyto3),
not PC formula implementation.

Reproducibility:
  • CPU vs GPU PC values differ <5% (expected from Cellpose stochasticity)
  • Multiple runs with same data yield identical PC (seed=42 in patch search)
  • Fully deterministic once segmentation masks are fixed
