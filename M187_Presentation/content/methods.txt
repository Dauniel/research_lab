METHODS

Pipeline Overview (6 Steps)

[Step 1: Load]
  • Input: Two TIF Z-stacks (condensate channel + nuclei channel)
  • Format: 55 × 185 × 259 pixels, 16-bit unsigned integer
  • Output: Two 3D arrays (Z, Y, X)

[Step 2: Denoise]
  • Model: Cellpose 3 DenoiseModel (cyto3 preset)
  • Applied to every Z-slice independently
  • Purpose: Sharpen condensate boundaries by suppressing shot noise
  • Key: Denoising only guides segmentation, NOT used to compute intensities

[Step 3: Segment]
  • Model: Cellpose 3 (cyto3, do_3D=True)
  • Processes full 3D volume simultaneously (XY, XZ, YZ planes merged)
  • Advantage over 2D: Tracks condensates consistently across Z-slices
  • Post-processing: 3D connected-component labeling on nuclei masks
    - Collapses 76 raw Cellpose labels → 5 true connected nuclei
    - Removes internal fragments from condensate texture interference
    - Binary mask coverage unchanged (pixel-level fidelity preserved)

[Step 4: Measure]
  • Metric extraction via scikit-image regionprops
  • Per-object per-Z metrics: area, centroid, mean intensity
  • Output: CSV measurements table

[Step 5: Volume]
  • Aggregate voxel counts per label across all 55 slices
  • Provides 3D volume for each condensate and nucleus
  • Output: volumes.csv

[Step 6: Partition Coefficient (Fabrini Method)]

Background Subtraction:
  B = min(all voxel intensities across 3D stack)
  → Removes camera baseline + autofluorescence offset

Condensate Density:
  mask = voxels inside BOTH condensate AND nucleus
  density_cond = mean( clip(pixel - B, 0) ) over mask

Dilute Density (Robust Approach):
  1. Find all valid 10×10×10 patches entirely within nuclear dilute region
  2. Compute mean intensity for each patch (after B subtraction)
  3. Sort by intensity
  4. Take average of lowest 50 patches
  → Mimics researcher's manual selection of "quietest spot"
  → Deterministic, seed-independent, stable result

Partition Coefficient:
  PC = density_cond / density_dilute

Key Improvements Enabling PC Matching (6.32 reference vs 6.297 pipeline)

1. Background Subtraction (April 25)
   • Reference PC was computed with B subtracted; old pipeline lacked this
   • Single largest jump in accuracy
   • Implementation: B = cond_stack.min()

2. Connected-Component Nuclei Cleanup (April 30)
   • Cellpose splits nuclei into ~15-25 fragments
   • 3D connected components collapse to true contiguous regions (76→5)
   • Cleans up dilute-phase pixel selection without changing coverage

3. Lowest-Patch Dilute Density (April 30)
   • Old approach: one random patch (PC swing from 4.3–6.0 depending on seed)
   • New approach: 50 lowest-intensity patches (PC = 5.213, stable)
   • Matches biological intuition (researchers pick quiet spots)
   • Further refinement with bottom-50 patches → PC = 6.297 (final)
